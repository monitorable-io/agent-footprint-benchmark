# Agent footprint benchmark

What Linux server monitoring agents cost the server they watch: memory, CPU,
disk writes, network bytes, install time and on-disk size, measured on
identical cheap VPSes over 24 hours, three times, with every 10-second sample
published here.

**Status: harness under construction (2026-10-29).** No results yet. The
method is in the Monitorable platform repo's design doc; this README grows
into the reproduce-it-yourself guide as the harness lands.
